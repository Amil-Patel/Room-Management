# MeetSpace Frontend

Angular 18 + Tailwind CSS client for the Meeting Room Booking System.

## Setup

```powershell
npm install
npm start
```

App runs at `http://localhost:4200` and calls the API at `http://localhost:8000/api/v1`.

Update API URLs in `src/environments/environment.ts` if needed.

## Main screens

- Login / Register
- Dashboard (admin room management + user availability search & booking)
- Bookings (upcoming / past, edit, cancel)
